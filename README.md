# Personal Profile Website

A personal profile webpage built using HTML and CSS and intended for GitHub Pages.

## Files
- `index.html` — webpage structure and content
- `style.css` — styling and responsive layout
- `images/profile.jpg` — profile photograph

## Projects shown
- CodeArena — Online Code Evaluation System
- SpendWise — Personal Expense Tracker
- Hotel Management System
- UniBook — University Room Booking System

## Before submission
1. Upload `index.html`, `style.css`, and the `images` folder to the root of your GitHub repository.
2. Make sure `images/profile.jpg` is present so the profile photograph loads.
3. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Open the generated GitHub Pages URL and check the page before submitting it.
